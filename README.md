# FengChou Elementary — Bilingual Site

臺中市神岡區豐洲國民小學雙語網站 · A free bilingual website by **My Culture Connect 人師教育協會**.

- **Live:** https://fces.taiwan-bilingual.org/ (sub-domain on the `taiwan-bilingual.org` umbrella)
- **Model:** Taibao Elementary (`tbps-bilingual`) design system — ink-blue `#1F3A5F` + bronze `#B07D3C`, pure-white, Playfair + Lato + PingFang.
- **Type scale:** Yangming JHS standard — body 20/23px, secondary text ≥17/19px (px only, no rem).

## Pages
- `index.html` — Home (hero, century history, **Tug-of-War signature block**, principal teaser, student life, photo band, contact)
- `principal/` — Principal Huang Pao-sheng (“the lamplighter”), four commitments, 15 principals since 1922
- `news/` — News, two forms (per Luke / Guangxing model): **articles** (full text + photos) and **photo galleries** (brief + photos). Generated by `build_news.py`.
- `bilingual-campus/` — Immersive-English intro + **Word of the Day** (7 cards, 🔊 Web Speech + ▶ video) + **Classroom English** + **Bilingual Announcements** playlists.
- Festivals — external link to the shared MCC festivals hub (no `?from=` to avoid a broken back-strip; copying into the taiwan-bilingual umbrella is a future option).

## Build / regenerate news
```
python3 build_news.py        # rewrites news/index.html + all news/<slug>/
```
Photos live in `photos/` (banners, portrait, life cards) and `news-img/` (card thumbs + `gallery/<slug>/`). Source originals are in the vault folder `跨縣市學校服務/台中市/豐洲國小/`.
